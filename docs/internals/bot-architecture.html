Bot context and runtime policy

BotTurnContextMaps the thread ID to a bot and project. It loads bot instructions, project guidance, preferred sources, and learning. Home also gets working notes.

BotRuntimePolicyThe orchestrator resolves this policy before execution. It applies MCP grants and runtime restrictions. Codex and Claude disable native memory for bot threads.

Task results in Home

BotTaskService reads the work thread's status and saves the result run ID. The task card shows the status and opens the saved result or the work thread. For a direct task, the Home agent can use t3_bot to request a follow-up turn in Home when the task completes successfully.
